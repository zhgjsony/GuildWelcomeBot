## GuildWelcomeBot （公会迎新助手）

**GuildWelcomeBot** 是一款专为魔兽世界（WoW）设计的轻量级、智能公会自动欢迎插件。它能够在新成员加入公会时自动发送个性化的欢迎语，帮助公会营造热情友好的团队氛围。

### ✨ 核心功能

*   **智能新成员识别**：动态对接游戏内置的全球化系统文本，精准识别新成员加入公会的系统广播。
*   **自定义欢迎语**：支持自由配置欢迎内容，提供 `{name}` 动态占位符，自动提取并替换为新人的名字（自动裁剪跨服服务器后缀）。
*   **发话延迟控制**：可自由调整欢迎语的发送延迟（秒），避免多名新成员同时加入时造成聊天频道刷屏或卡顿。
*   **原生配置面板**：完美嵌合魔兽世界原生的系统设置菜单，支持复选框开关、延迟调节与文本输入。

### ⌨️ 快捷命令

在游戏聊天框中输入以下命令可快速呼出设置面板：

*   `/gwb`

## GuildWelcomeBot

**GuildWelcomeBot** is a lightweight and intelligent guild welcoming addon designed for World of Warcraft (WoW). It automatically sends customizable welcome messages when new members join the guild, helping you foster a warm and welcoming community atmosphere.

### ✨ Key Features

*   **Smart Member Detection:** Dynamically binds to the game's localized system strings to precisely detect guild joining announcements.
*   **Customizable Welcomes:** Supports tailor-made greeting messages with a dynamic `{name}` placeholder, which automatically extracts and replaces the newcomer's name (with cross-realm suffixes neatly stripped).
*   **Delivery Delay Control:** Easily adjust the message delivery delay (in seconds) to prevent chat flood or lag when multiple players join consecutively.
*   **Native Interface Options:** Perfectly integrates into WoW's native Settings menu, featuring a checkbox toggle, text input, and delay adjustment.

### ⌨️ Slash Commands

Type the following command in the chat box to quickly open the configuration panel:

*   `/gwb`
