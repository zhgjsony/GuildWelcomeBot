# GuildWelcomeBot

![Setting](https://i.imgur.com/d9ZuUzr.png) 

**简体中文：**

一款专为魔兽正式服设计的轻量级公会迎新插件，支持在选项菜单中可视化自定义欢迎文本与发话延迟。

初始版本仅支持简体中文。

**English:**

A lightweight guild welcoming addon for WoW Retail, allowing users to visually customize welcome messages and chat delays within the settings menu.

This initial release supports Simplified Chinese only.
